# docs/navaal — the guiding folder

Read these in order at the start of **every** session. They are the project's memory.

| File | What it is | Who writes it |
|---|---|---|
| `00-CONSTITUTION.md` | **Laws.** Each one was learned by being wrong. A law beats an instruction. | Owner + Cowork |
| `01-NORTH-STAR.md` | The goal, the ladder to #1, the scoreboard, the log | Cowork; CC appends to §10 LOG |
| `02-BACKLOG.md` | **What is left.** Phased, ordered, with status. Authoritative for WHAT. | CC updates status every session |
| `03-PROTOCOL.md` | How a session runs: orient → pick → do → verify → write back → report → stop | Owner + Cowork |
| `04-DECISIONS.md` | Settled decisions incl. final pricing. Do not re-litigate. | Owner only |
| `05-EVIDENCE.md` | Verified facts: the ladder, competitor pricing, churn maths, store shapes. Do not re-research. | Cowork |
| `06-HUMAN-QUEUE.md` | Tasks an agent cannot do. One queue, worked in batches. | CC appends; owner clears |

## The three rules of this folder
1. **`02-BACKLOG.md` is authoritative for WHAT, never blindly for STATUS.** Reconcile against the code each session.
2. **Anything in `05-EVIDENCE.md` is not re-researched.** If it looks stale, re-read the source and update the file.
3. **Anything in `04-DECISIONS.md` is not reopened without new evidence.** Bring the evidence and stop.

## The goal, in one line
Be the **#1 app in the Shopify App Store SEO category**, with real paying merchants and real revenue.
Everything in this folder exists to stop us drifting off that.
